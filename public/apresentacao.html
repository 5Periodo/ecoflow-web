Temática · Pitch

O Problema Real

79M
toneladas de resíduos geradas no Brasil por ano
4%
apenas da taxa de reciclagem efetiva em condomínios
0
ferramentas acessíveis de engajamento para síndicos
💡

Nossa Solução

O EcoFlow transforma descarte de resíduos em uma experiência gamificada. Moradores escaneiam QR Codes nos ecopoints do condomínio, acumulam pontos por tipo de material reciclado e trocam por recompensas reais — enquanto o síndico acompanha tudo em tempo real pelo painel web.

📱 App para moradores — escanear, pontuar, resgatar 🖥️ Painel para síndicos — gerenciar, aprovar, analisar 🔌 API robusta — segura, documentada, escalável

Recursos Extras · Diferencial

Além do que foi visto em sala

📖

Swagger / OpenAPI

Documentação interativa completa em /api/docs. Todos os endpoints documentados com schemas, exemplos e autenticação JWT integrada.

🎮

Gamificação Completa

Sistema de níveis por pontos acumulados, ranking mensal entre apartamentos, histórico de conquistas e recompensas trocáveis via cupom — tudo integrado ponta a ponta.

📷

QR Code End-to-End

Web gera o QR Code do ecopoint (hash único), Mobile escaneia e valida o hash na API, fechando um fluxo completo de rastreabilidade do descarte.

🐳

Docker & CI Ready

Dockerfile e docker-compose.yml prontos para deploy. Banco PostgreSQL containerizado. Projeto deployável em qualquer cloud com um único comando.

🔐

Segurança em Camadas

Senhas com Bcrypt, tokens JWT stateless, roles de acesso, whitelist de campos (ValidationPipe), CORS configurado e armazenamento seguro no mobile.

📊

Análises & Métricas

Dashboard com gráficos de linha e barra no Web (Chart.js), metas mensais com status automático (EM_ANDAMENTO / ATINGIDA / NAO_ATINGIDA) e ranking histórico persistido.

3

Morador escaneia o QR Code do ecopoint

Seleciona tipo de material, informa o peso, tira foto — registro enviado à API com status PENDENTE.

📱 Mobile
4
✅
Síndico valida o descarte

Vê a foto, aprova ou nega — API atribui pontos ao morador e atualiza o ranking.

🖥️ Web
5
🎁
Morador resgata recompensas

Troca pontos por cupons no App — síndico valida o cupom pelo painel web.
